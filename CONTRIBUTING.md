# Как помочь проекту rulemma

Мы открыты к правкам словарей, новым регрессионным тестам и сложным примерам для бенчмарков.

## Как исправить лемму для слова

1. Добавьте строку `слово<TAB>лемма` в `data/overrides.tsv` (в нижнем регистре, буква `ё` приводится к `е`).
2. Добавьте проверку в `lemmatizer_test.go` и `tests/test_python.py`.
3. Прогоните тесты Go и Python:
   ```bash
   make build
   make test
   ```

## Как добавить или заблокировать пару `прилагательное -> существительное`

- Измените списки `EXTRA_RELATIONAL` или `BLOCKED_PAIRS` в `tools/build_adj_noun.py`.
- Добавьте положительный пример и защитный контрпример в `TestAdjToNounAndSemanticKey`.
- Не добавляйте качественные прилагательные к абстрактным существительным на `-ость` (например, `тихий -> тишина`, `умный -> ум`): они ломают поисковую дедупликацию и склеивают разные товары.

## Требования к коду

- Ядро на Go (`github.com/DimaKorshikov/rulemma`) должно оставаться без внешних зависимостей.
- Пакет Python должен работать только на стандартной библиотеке (`ctypes`), без сторонних runtime-пакетов.
- Перед отправкой Pull Request убедитесь, что `go test -v -race ./...` и `make test-py` проходят без ошибок.
