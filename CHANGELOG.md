# Changelog

Все заметные изменения в `rulemma` фиксируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), а проект следует [Semantic Versioning 2.0.0](https://semver.org/lang/ru/).

## [0.2.2] - 2026-11-27

Патч-релиз системного качества словаря со **100% обратной совместимостью Go API, C-ABI, Python API и CLI**.

### Исправлено (системные правила в `tools/build_dicts.py`)

- **Системная нормализация полных причастий (`PRTF`) в прилагательную лемму (`3 755` словоформ):**
  - В OpenCorpora полные причастия по умолчанию лемматизируются в инфинитив глагола (`увлажняющая -> увлажнять`, `направляющие -> направлять`, `утепленные -> утеплить`, `встроенная -> встроить`, `регулируемый -> регулировать`, `эмалированная -> эмалировать`, `замороженные -> заморозить`, `чистящее -> чистить`, `греющий -> греть`, `отбеливающий -> отбеливать`, `охлаждающая -> охлаждать`, `сгущенное -> сгустить`, `раскладывающаяся -> раскладываться`, `моющиеся -> мыться`).
  - В `tools/build_dicts.py` добавлено правило приведения полных причастий `PRTF` к именительной форме мужского рода единственного числа (`masc,sing,nomn`), при этом глаголы (`VERB`/`INFN`), краткие причастия (`PRTS`), деепричастия (`GRND`) и субстантивированные существительные (`NOUN`) не затрагиваются.
  - Автоматически сгенерировано **`+6 428` форм согласования** по родам и числам в `data/adj_forms.tsv.gz` (`71 331 -> 74 094` форм, также очищены устаревшие глагольные ключи и нормализованы `|plur|plur -> ||plur` и `ё -> е` в ключах), благодаря чему `AgreeAdjective` и `BuildSEOName` теперь согласуют тысячи причастий (`утепленные + Куртка -> утеплённая`, `эмалированные + Ведро -> эмалированное`).
- **Системная защита 2-буквенных слов (`TWO_LETTER_GRAMMAR_ALLOW`, `651` защищённых слов):**
  - Зафиксирован исчерпывающий список реальных 2-буквенных словоформ русского языка (`во->в`, `со->с`, `ко->к`, `об->о`, `ее/ей/ею->она`, `им/их->они`, `та/те/ту->тот`, `ел/ем->есть`, `чо/чё/шо->что`, `юн->юный`, `гг->год`). Все остальные 2-буквенные токены и сокращения (`ок`, `ср`, `вв`, `см`, `мм`, `мг`, `кг`, `вт`, `мл`, `шт`, `ам`, `ат`, `ив`, `ис`, `аб`, `ав`, `ид`, `уз`, `од`, `эр`, `эд` и др.) больше не искажаются архаичными словарными записями OpenCorpora (`ок->около`, `вв->век`, `ср->сравнить`, `ам->ама`, `ат->ата`, `ив->ива`).
- **Системная защита от ложных `Name,plur,gent` и разговорных `Infr,plur,gent` (`759` слов):**
  - Отсечены коллизии с родительным падежом множественного числа редких/вымышленных имён OpenCorpora (`шакл->шакла`, `лайн->лайна`, `айс->айса`, `лит->лита`, `рип->рипа`, `тай->тая`, `изи->изя`, `авант->аванта`, `абрамов->абрам`) и 2–3-буквенные `Infr,plur,gent` (`обж->обжа`, `сот->сотня`) при полном сохранении настоящих форм существительных (`ног->нога`, `губ->губа`, `шин->шина`, `рук->рука`, `фар->фара`, `роз->роза`, `полов->пол`).
- **Универсальная защита нарицательных существительных в косвенных падежах и мн.ч. для слов любой длины (`430` слов — правила `2d`/`2e`/`2f`):**
  - `ADJS` vs `NOUN` (`170` слов): `ковров->ковер`, `шлангов->шланг`, `румяна->румяна`, `саженцев->саженец`, `коньков->конек`, `поводков->поводок`, `кранов->кран`, `мяты->мята`, `тортов->торт`, `кабачков->кабачок`, `пультов->пульт`, `кактусов->кактус`, `чаем->чай`, `черенков->черенок`, `торцов->торец`, `брусков->брусок`, `фланцев->фланец`, `фиников->финик` и др.
  - `VERB,impr`/`GRND` vs `NOUN` (`33` слова): `мочи->моча`, `сколов->скол`, `голубей->голубь`, `лишая->лишай`, `тли->тля`, `вшей->вошь`, `уколов->укол`, `запоров->запор`, `угрей->угорь`, `струи->струя`, `приколов->прикол`, `хмеля->хмель`, `щелочи->щелочь`, `такелажа->такелаж`, `слесарь->слесарь`, `перегноя->перегной`, `отеки->отек` и др.
  - Косвенные `Name`/`Surn`/`Patr`/`Geox` и спорные `Surn` на `-ов/-ев` vs `NOUN` (`227` слов): `саморезы->саморез`, `цветами/цветам/цветах->цвет`, `альфу->альфа`, `турбину->турбина`, `свинины->свинина`, `рубцов->рубец`, `усов->ус`, `горшков->горшок`, `рогов->рог`, `ульи->улей`, `ивы->ива`, `астры->астра`, `косу->коса`, `пиле->пила`, `газе->газ`, `тую->туя`, `течи->течь`, `вощины->вощина`, `люцерны->люцерна`, `мотокосу->мотокоса`, `броне->броня` (при сохранении реальных городов и имён `субару`, `ростов`, `германии`, `уфе`, `туле`).
- **Общеязыковые правки в `data/overrides.tsv` (`347 -> 383`):** `мин -> мин`, `рус -> рус`, `осп -> осп`, `хот -> хот`, `фит -> фит`, `мен -> мен`, `кар -> кар`, `пар -> пар`, `моли -> моль`, `драй -> драй`, `джиг -> джиг`, `коп -> коп`, `полы / полов / полам / полом -> пол`, `мини -> мини`, `угги -> угги`, `бини -> бини`, `пэды -> пэд`, `озу -> озу`, `сиз -> сиз`, `рал -> рал`, `дез -> дез`, `вент -> вент`, `табл -> табл`, `пав -> пав`, `вен -> вена`, `ямы -> яма`, `фару -> фара`, `газу -> газ`, `клади -> кладь`, `суши -> суши`, `рамен -> рамен`, `биты -> бита`, `лосины -> лосины`.
- **Расширение покрытия базового словаря (`data/lemmas.tsv.gz`):** `169 569 -> 204 839` очищенных словоформ (`1.13 МБ` сжато), обновлён `data/manifest.json` (`dict_version: 2026.11.2`).

### Изменения поведения на спорных омонимах (зафиксированы в `tests/golden/`)

- Полные причастия (`PRTF`) теперь лемматизируются в прилагательную форму (`masc,sing,nomn`), а не в глагол.
- `ок -> ок` (вместо `около`), `ср -> ср` (вместо `сравнить`), `вв -> вв` (вместо `век`), `обж -> обж` (вместо `обжа`), `мин -> мин` (вместо `мина`), `рус -> рус` (вместо `русый`), `осп -> осп` (вместо `оспа`), `пар -> пар` (вместо `пара`), `коп -> коп` (вместо `копа`), `моли -> моль` (вместо `молить`), `полы / полов / полам / полом -> пол`.

## [0.2.1] - 2026-11-27

Патч-релиз со **100% обратной совместимостью Go API, C-ABI, Python API и CLI**: ни одна существующая сигнатура или режим вывода не изменены.

### Исправлено

- **Словарь и базовые `data/overrides.tsv` (`218 -> 347` правок):**
  - Закрыты 5 известных промахов базового словаря из релиза `v0.2.0`: `отпариватели -> отпариватель`, `дочерей -> дочь`, `воробьев -> воробей`, `автодорог -> автодорога`, `большие / большая / больших -> большой` (см. раздел о спорных омонимах ниже).
  - Исправлена лемматизация и согласование 7 причастий-определений (`плавающие`, `развивающие`, `обслуживаемые`, `оцинкованные`, `орнаментированные`, `встраиваемые`, `оксидированные` — теперь лемматизируются в прилагательную форму, а не в глагол; в `data/adj_forms.tsv.gz` добавлены недостающие 4 формы множественного числа `||plur`, итого `71 331` форм).
  - Защищены сокращения единиц измерения (`см -> см` вместо `смотреть`, а также `мм`, `мг`, `кг`, `вт`, `квт`, `л`, `мл`, `шт`, `м`, `г`), однобуквенные обозначения (`б`, `д`, `е`, `т` — не превращаются в `быть`/`далее`/`так`) и товарные омонимы (`мелки -> мелок`, `полка -> полка`, бренд `делонги -> делонги`).
- **CLI (`cmd/rulemma`):** исправлена генерация заголовков в `rulemma tsv --header` для режимов `--mode semkey` (`\tsemantic_key`) и `--mode all` (`\tlemma_text\tlemma_key\tsemantic_key`), ранее по ошибке выводивших `\tlemma_text`.
- **Сборка Python-пакета (`setup.py`):** при установке колеса файлы `data/` копируются в `build_lib`, не оставляя устаревшую копию `python/rulemma/data/` в дереве исходников.

### Изменения поведения на спорных омонимах (зафиксированы в `tests/golden/`)

- `воробьев` → `воробей` (ранее оставалось `воробьев` как омоним фамилии).
- `большая`, `большие`, `больших`, `большими`, `большим`, `большую`, `большому` → `большой` (ранее маппилось на сравнительную степень `больший`).
- `см` → `см` (ранее лемматизировалось в глагол `смотреть`).
- `цветов` намеренно оставлено без изменений (`цвет`) как честный бесконтекстный омоним (`цвет` / `цветок`).

### Добавлено

- **Go API:**
  - `Version`, `ABIVersion`, `DictSchemaVersion` ([version.go](version.go)).
  - `NormalizePhrase(text string, keepYo bool) string` — единая быстрая нормализация фраз без regex (с опциональным сохранением `ё`).
  - `MakeStopWords(words []string) map[string]struct{}` — построение нормализованного набора стоп-слов.
  - `LoadFS(fsys fs.FS, opts Options)`, `LoadManifest(dataDir)` и `LoadManifestFS(fsys)` ([dict.go](dict.go)).
  - Опциональный субпакет [`rulemma/embedded`](embedded/embedded.go) (`//go:embed`) для подключения словарей одной строкой `embedded.Load()` без поиска папки `data/` на диске.
- **Словари:** файл метаданных и контрольных сумм [`data/manifest.json`](data/manifest.json) (`schema_version: 1`) и скрипт верификации [`tools/update_manifest.py`](tools/update_manifest.py).
- **C-ABI (`capi/capi.go`, строго append-only, `ABI=1`):**
  - `rulemma_abi_version()`, `rulemma_version()`.
  - `rulemma_normalize_phrase(text, keepYo)`.
  - `rulemma_lemma_key_stop`, `rulemma_semantic_key_stop`, `rulemma_batch_stop` (проброс кастомных стоп-слов в C-API и параллельные батчи Go).
  - Новые режимы `mode=5` (`normalize_phrase`, `ё -> е`) и `mode=6` (`normalize_phrase`, `keep_yo=true`) в `rulemma_batch`.
- **Python API (`python/rulemma/`):**
  - `DEFAULT_STOP_WORDS`, standalone и метод `normalize_phrase(text, *, keep_yo=False)`, пакетный `normalize_batch(...)`.
  - Свойства `abi_version` и `library_version` с проверкой совместимости C-ABI при загрузке `librulemma.so`/`.dylib`.
  - Keyword-аргумент `stopwords=` в `lemma_key`, `semantic_key`, `lemma_keys`, `semantic_keys`, `lemmatize_and_keys` и `lemmatize_tsv` (работает как на нативном CGO-бэкенде, так и на CLI-фоллбэке).
- **CLI (`cmd/rulemma`):** подкоманда `version`, вывод версии/ABI/манифеста в `info`, флаги `--stopwords` (`FILE | none | w1,w2`) и `--keep-yo`, режим `--mode norm`, поддержка `semkey`/`all`/`norm` в `bench`.
- **Тесты, примеры и бенчмарк:**
  - Золотые регрессионные наборы [`tests/golden/golden_lemmas.tsv`](tests/golden/golden_lemmas.tsv) (540 слов) и [`tests/golden/golden_ecommerce.tsv`](tests/golden/golden_ecommerce.tsv) (105 фраз/кейсов), проверяемые и в Go, и в Python.
  - 12 самодостаточных проверяемых примеров в [`examples/01..12`](examples/README.md) с автотестом [`tests/test_examples.py`](tests/test_examples.py).
  - Обновлённый [`benchmarks/compare_models.py`](benchmarks/compare_models.py): добавлены `SteosMorphy`, `mawo-pymorphy3` и изолированный замер пикового RSS RAM в отдельном подпроцессе.

## [0.2.0] - 2026-11-26

### Добавлено

- Первый публичный open-source релиз `rulemma` под лицензией MIT.
- Ядро на Go (`Load`, `LoadWithOptions`, `Word`, `Lemmatize`, `LemmatizeString`, `LemmaKey`, `LemmaKeyWithStop`, `SemanticKey`, `SemanticKeyWithStop`, `AdjToNoun`, `TypeGram`, `AgreeAdjective`, `AgreeAdjectiveGram`, `BuildSEOName`).
- Очищенные словари `data/` (`169 569` словоформ, `71 327` форм прилагательных, `4 661` товарный тип, `4 030` пар `adj -> noun`, `218` правок `overrides.tsv`).
- Нативные Python-биндинги (`ctypes` → `librulemma.so`/`.dylib`) и потоковый CLI (`info`, `lemmatize`, `tsv`, `bench`, `seoname`).
- Воспроизводимый бенчмарк против `pymorphy3`, `Natasha`, `simplemma`, `pymystem3` и `SnowballStemmer`.
